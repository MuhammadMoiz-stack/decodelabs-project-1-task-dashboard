# TaskMaster - Modern Task Management Dashboard

## 🚀 Project Overview
TaskMaster is a modern, professional, and fully responsive Task Management Dashboard designed for high-productivity environments. Built with a SaaS-first mindset, it provides users with a clean interface to manage daily tasks, track productivity through real-time statistics, and maintain a clear visual hierarchy of their priorities.

This project was developed as part of a Senior Frontend Development internship requirement, focusing on clean code, semantic HTML, and advanced CSS layouts without the use of external frameworks.

## ✨ Features
- **Real-time Dashboard Statistics**: Automatically updates total, completed, and pending tasks.
- **Productivity Analytics**: Visualizes progress with a percentage-based productivity tracker.
- **Dynamic Task Management**: Add new tasks with priority levels and toggle completion status.
- **Modern UI/UX**: Professional "Mocha Mousse" & "Ethereal Blue" color palette.
- **Mobile-First Responsive Design**: Optimized for seamless use across Mobile, Tablet, and Desktop.
- **SaaS Aesthetic**: High-quality typography using Google Fonts (Roboto & Inter).
- **Smooth Animations**: Interactive hover effects and card transitions.

## 🛠️ Tech Stack
- **HTML5**: Semantic structure for SEO and accessibility.
- **CSS3**: Custom properties (variables), Flexbox, and CSS Grid.
- **Vanilla JavaScript**: DOM manipulation and state management.
- **Google Fonts**: Roboto (Display) and Inter (Reading).

## 📱 Responsive Design Information
The project follows a strict mobile-first approach with the following breakpoints:
- **Mobile**: 320px - 767px (Single column layout, hamburger menu)
- **Tablet**: 768px - 1023px (Two-column grid, expanded stats)
- **Desktop**: 1024px+ (Four-column grid, horizontal navigation)
